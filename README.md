# jizhi0v0/homebrew-tap

Homebrew casks for [DuoUpdater](https://duoupdater.app/).

```sh
brew install --cask jizhi0v0/tap/duoupdater
```

DuoUpdater updates itself (Sparkle), so the cask is marked `auto_updates`:
`brew upgrade` leaves it to the app. The cask is bumped by DuoUpdater's release
script on every release.
